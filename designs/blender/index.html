3D-print · Blender MCP + Claude Code

Fra prompt
til print.

Alt 3D på denne side er lavet ved at lade Claude Code styre Blender gennem MCP-integrationen.

  1. 01

    Modellér i kode

    Claude Code skriver Python mod Blenders API (bpy) og kører det direkte i Blender via MCP. Stjernen bygges af de samme ni polygoner som SVG-logoet, ekstruderet med flad bund og spidser, der rejser sig.

  2. 02

    Render og se efter

    Claude renderer en hurtig preview, ser selv på billedet og retter. Under arbejdet med denne side opdagede den på den måde, at ringene lå ved 3D-markøren i stedet for i centrum.

  3. 03

    Tjek printbarheden

    Delene smeltes sammen med en boolean union og måles: lukket mesh (manifold), mål i millimeter, volumen og flader, der hænger over mere end 45°.

  4. 04

    Eksportér

    Modellen skaleres til den ønskede størrelse og eksporteres som STL eller 3MF i millimeter, klar til en slicer.

  5. 05

    Slice og print

    Sliceren deler modellen i lag. Med flad bund og uden overhæng burde stjernen kunne printes uden support.
